# 🎬 AnimeDex - Popular Anime Encyclopedia

**AnimeDex** is a Single Page Application (SPA) web app that presents real-time anime and character data. This project utilizes the free REST API from MyAnimeList via **Jikan API** and was built to fulfill the final project requirements for the **Learn Front-End Web Development for Beginners** course in the **AI Full-Stack Developer - Dicoding Academy** learning path.

---

## 🚀 Key Features

- **Top Recommendations:** Displays the top 5 anime picks for today.
- **Currently Airing Season:** A list of anime currently broadcasting this season.
- **Most Popular Characters:** Iconic anime characters along with their user favorite counts.
- **Accessibility & Performance:** Supports full keyboard navigation (`Tab` & `Enter`) and is optimized for a high Lighthouse score.
- **Responsive Web Design:** Adaptive layout for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic document structure (`<header>`, `<main>`, `<aside>`, `<footer>`).
- **CSS3:** Responsive layouts using Flexbox and CSS Grid.
- **JavaScript (ES6 Modules):** Handles SPA routing logic, DOM manipulation, and API fetching.
- **Jikan API v4:** Public REST API to fetch real-time MyAnimeList data.
